# Spec-Driven Repository Template

Copy this repository to start a project with a lightweight governance and
specification foundation.

Before product implementation begins:

1. Replace every bracketed placeholder in `specs/Project-Spec.md` with the
   project's goal or mission and initial behavioral contract.
2. Rename `specs/Project-Spec.md` to the project's authoritative specification
   name and update references to it in `AGENTS.md` and `specs/README.md`.
3. Tailor the review criteria in `TEAM.md` and any project-specific guidance
   in `AGENTS.md`.
4. Keep behavior changes, tests, the changelog, and release impact aligned as
   described in the governance files.

This template intentionally makes no product, platform, privacy, security, or
behavioral claims. The adopting project defines those commitments in its
authoritative specification.
